# 티어 탭 가로·세로 카탈로그 배치 설계

## 목표

기존 티어표 편집, 크기 조절, 니케 클릭·드래그 배치, 검색·필터, 접힘 기능을 유지하면서 전체 니케 목록을 티어표 오른쪽에 놓는 가로 모드를 추가한다. 사용자가 선택한 가로·세로 모드는 새로고침 뒤에도 복원한다.

## 용어

- 가로 모드: 티어표 왼쪽, 전체 니케 목록 오른쪽의 2열 배치
- 세로 모드: 현재와 동일하게 티어표 아래에 전체 니케 목록을 두는 배치
- 카탈로그: 전체 니케 목록의 검색, 필터, 카드 목록을 포함한 영역

## 상태와 영속성

`TierBoard`가 `bottom | side` 형식의 카탈로그 배치 상태를 소유한다. 별도의 버전이 포함된 로컬 저장소 키에 상태를 저장하고, 저장값이 없거나 유효하지 않으면 기존 동작인 세로 모드를 기본값으로 사용한다.

설정 패널은 현재 모드와 변경 콜백만 전달받는다. 검색어, 선택 필터, 접힘 상태는 현재처럼 `TierNikkeCatalog`가 소유하므로 모드를 바꿔도 유지된다.

## 설정 UI

니케 티어 설정 패널 헤더의 닫기 버튼 왼쪽에 단일 스위치를 추가한다.

`가로모드 [스위치] 세로모드`

- 스위치 왼쪽은 가로 모드, 오른쪽은 세로 모드다.
- 위치, 활성 색상, `role="switch"`, `aria-checked`로 상태를 함께 전달한다.
- 닫기 버튼과 기존 설정 항목의 동작은 변경하지 않는다.

## 전체 배치

세로 모드는 현재 단일 열 DOM 배치와 카탈로그의 아래 방향 접기·펼치기를 유지한다.

가로 모드는 티어표와 카탈로그를 같은 행에 둔다. 티어표는 현재 사용자의 로컬 크기와 좌우 크기 조절을 유지하고, 카탈로그는 남은 공간을 사용한다. 카탈로그 외부 높이는 티어표가 실제 렌더링된 높이를 기준으로 맞춘다. 티어표 크기 조절, 설정 패널 열기, 창 크기 변경으로 높이가 바뀌면 측정값도 갱신한다.

카탈로그가 접히면 티어표 폭을 강제로 바꾸지 않고 카탈로그 열만 접힘 버튼을 표시할 최소 폭으로 축소한다. 펼치면 버튼 위치에서 오른쪽 방향으로 내용이 복원된다.

## 가로 모드 카탈로그

- 일반적인 데스크톱 폭에서는 니케 카드를 한 줄에 6개 표시한다.
- 사용 가능한 폭이 줄면 열 수를 5개 이하로 단계적으로 줄인다.
- 6열 미만에서는 이미지, 이름 글자, 내부 여백, 카드 간격을 함께 축소한다.
- 카탈로그의 헤더와 검색·필터는 고정하고 카드 영역만 내부 세로 스크롤한다.
- 접힘 버튼은 카탈로그 좌측 상단에 둔다.
- 접힘 아이콘은 가로 방향 동작을 나타내며, 닫힐 때 왼쪽으로 접히고 열릴 때 오른쪽으로 펼쳐지는 의미를 전달한다.
- 검색창은 가용 폭에 맞춰 축소한다.
- 필터 버튼은 줄바꿈하지 않는 한 줄을 유지하고 넘치는 내용은 가로 스크롤로 접근한다.

세로 모드에서는 기존 5/7/12열 반응형 카드 그리드, 검색 UI, 아래 방향 접힘 버튼을 그대로 유지한다.

## 기존 기능 보존

다음 동작과 데이터 흐름은 변경하지 않는다.

- 카탈로그 이미지 클릭으로 마지막 티어에 추가
- 카탈로그와 티어 사이 드래그, 같은 티어 및 다른 티어 정렬
- 스크롤 중 포인터에 정렬되는 공용 `DragOverlay`
- 드래그 삽입 위치 계산과 투명 자리 표시자
- 배치된 니케의 회색 표시
- 티어 줄 이름·색상·순서 편집 및 초기화
- 티어표 좌우 크기 조절, 카드 크기 선택, 로컬 레이아웃 초기화
- 서버 저장 및 충돌 처리

## 컴포넌트 책임

- `TierBoard`: 배치 상태 로드·저장, 모드별 외부 그리드, 티어표 높이 측정, 설정 및 카탈로그에 모드 전달
- `TierSettingsPanel`: 가로·세로 스위치 표시와 변경 이벤트 전달
- `TierNikkeCatalog`: 동일한 검색·필터·카드 상태를 재사용하며 모드별 헤더, 접힘 방향, 그리드 및 스크롤 표현 적용
- 배치 상태 파서: 잘못된 로컬 저장값을 세로 모드로 복구하는 작은 순수 함수

## 접근성

- 모드 토글은 키보드로 조작 가능한 단일 스위치로 구현한다.
- 두 모드의 접힘 버튼은 현재 상태에 맞는 `aria-expanded`, `aria-label`, `title`을 제공한다.
- 카탈로그 콘텐츠는 접힌 상태에서 키보드 포커스 대상이 되지 않도록 렌더링하지 않는다.

## 테스트와 검증

1. 배치 상태 파서의 기본값, 유효값, 잘못된 저장값을 단위 테스트한다.
2. 설정 패널에 단일 스위치와 올바른 상태 전달이 있는지 검사한다.
3. 가로 모드 외부 2열 배치, 높이 동기화, 카탈로그 내부 스크롤 구조를 검사한다.
4. 기본 6열과 6열 미만 카드 축소 규칙, 필터 한 줄 유지 규칙을 검사한다.
5. 세로 모드의 기존 클래스와 접힘 동작이 남아 있는지 회귀 테스트한다.
6. 기존 티어 관련 전체 테스트, ESLint, 빌드를 실행한다.
7. 실행 중인 앱에서 가로·세로 전환, 새로고침 복원, 여러 창 너비, 좌우/상하 접힘, 검색·필터, 클릭·드래그를 확인한다.

## 제외 범위

- 배치 상태를 Supabase 계정 설정으로 동기화하지 않는다.
- 티어 데이터 형식과 API를 변경하지 않는다.
- 기존 티어표 카드 크기 규칙을 재설계하지 않는다.
- 카탈로그의 검색·필터 조건이나 니케 정렬 순서를 변경하지 않는다.
