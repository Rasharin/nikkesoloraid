# 유니온 레이드 구현 계획

승인된 설계: 덱 빌딩과 저장된 덱의 모드 전환, 행당 3덱/속성/다른 행 중복 강조, 마스터의 회차 예약·수정·개시·종료.

기존 솔로레이드 테이블과 추천 흐름은 유지한다. 유니온 일정과 사용자 덱은 별도 테이블에 저장한다. 페이지에서 모드를 관리하고 기존 덱 빌더와 저장 목록 컴포넌트는 선택적 props로 확장한다.

- [ ] `lib/union-raid.ts`, `tests/union-raid.test.ts`: 행 중복 및 일정 입력 검증을 테스트 후 구현.
- [ ] 유니온 테이블/RLS/원자적 일정 처리 함수 및 마스터 API 추가. 기존 예약 호출에 유니온 처리를 연결.
- [ ] `ImaginarySoloRaidTab`, `DeckBuilderSection`, `DeckSlot`: 저장 키 분리, 행별 속성, 3덱 배치와 중복 강조.
- [ ] 유니온 데이터 hook, 저장된 덱과 유레 관리 UI 추가. `app/page.tsx`에서 연결.
- [ ] 테스트, lint, build 및 브라우저 확인. DB 적용/권한 검증 결과를 구분하여 보고.

추가 패키지 의존성 없이 구현한다. 종료된 회차 기록은 보존하고 활성 회차가 없으면 기기 초안만 유지한다. 사용자 데이터 변경은 소유자에게만 허용하며 시즌 관리는 마스터 인증 후 실행한다.
